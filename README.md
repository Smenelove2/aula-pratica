# Aula Prática - Colaboração com GitHub

Repositório criado para uma aula prática com o objetivo de treinar colaboração em projetos utilizando **Fork**, **Branch**, **Commit**, **Push** e **Pull Request** no GitHub.

A proposta da atividade é simples: cada aluno deverá criar ou complementar uma função em Python, versionar sua alteração no próprio fork e depois enviar uma **Pull Request** para o repositório principal.

---

## Objetivo da atividade

Nesta prática, cada aluno irá:

- Fazer um **fork** deste repositório
- Clonar o próprio fork para a máquina
- Criar uma **branch**
- Implementar uma função sugerida no projeto
- Fazer `add`, `commit` e `push`
- Abrir uma **Pull Request** para este repositório

O foco da atividade não é apenas Python, mas principalmente o fluxo de colaboração com GitHub.
